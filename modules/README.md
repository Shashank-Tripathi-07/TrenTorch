# TrenTorch Modules

Your workspace for building ML systems from scratch.

## 🚀 Getting Started

```bash
tren module start 01    # Start Module 01: Tensors
```

This creates the module folder and opens Jupyter Lab.

## 📋 Workflow

1. `tren module start XX` - Create and start a module
2. Work in Jupyter Lab - Build your implementation
3. `tren module complete XX` - Test and export your work

## 📊 Progress

```bash
tren module status      # View your progress
tren module list        # See all available modules
```

Each module builds on previous ones. Complete them in order to build your ML framework!
